About

Built to demonstrate offline-first web technology.

This website uses a Service Worker to store the webpage in the browser cache.

When the internet connection disappears, the Service Worker intercepts the request and returns the cached version of the website.

That means the portfolio can continue working even without an internet connection.

Cache System

How this website works behind the scenes.

🌐

01. First Visit

Browser loads the website normally while connected to the internet.

⚙️

02. Service Worker

JavaScript registers a Service Worker that controls network requests.

💾

03. Cache Storage

The complete HTML page is stored inside the browser's Cache Storage.

📡

04. Offline

When the internet disappears, the Service Worker serves the cached page.
